Installation & Setup Guide

Everything you need to install Quirk Notes and configure local or cloud AI study tools.

Install on Android

Compatible with 64-bit devices on Android 8 or later (tablets and phones).

  1. Download Quirk-Notes.apk directly to your Android device.
  2. Open the file. If Android prompts, permit your browser to install unknown applications.
  3. Launch Quirk Notes from your application drawer.

To update, install the newer APK file over the existing installation. All your notebooks and data will be preserved.

Install on iPad

Requires iPadOS 17 or later with Apple Pencil support. Setup takes 2 minutes via Mac or PC.

  1. Download Quirk-Notes.ipa to your computer.
  2. Install Sideloadly or AltStore, and connect your iPad via cable.
  3. Open the .ipa file in the sideload utility and sign with your Apple ID.

Note: On free Apple Developer accounts, sideloaded applications must be re-signed every 7 days (AltStore can automate this over Wi-Fi).

Configure AI Study Tools

You can configure cloud AI via a free NVIDIA API key, a 100% offline local model, or both seamlessly.

Option A: Free NVIDIA NIM Key (Fast Cloud AI)

  1. Obtain your free API key at build.nvidia.com.
  2. In Quirk Notes, open Settings › AI Setup and paste your key.

Your key stays locally encrypted on your device. Only prompt context from the notebook you choose to study is transmitted.

Option B: 100% Offline Local Model

In Settings › AI Setup, tap Download Local Model. This performs a one-time 1.1 GB download of a quantized LLM. Once finished, flashcard generation, quizzes, and summaries work completely offline with zero internet access.

PWA Browser Edition

On iPad, Android, or desktop, open the Web Version in Safari or Chrome. Tap Share › Add to Home Screen to run full-screen offline with native ink.
